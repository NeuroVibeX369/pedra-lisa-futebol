# Атлас формы (kit) — схема 512×512

Каждая форма клуба — один PNG 512×512. Замена файла = новая форма, код не
трогаем.

**Координаты в этом файле — в СЕТКЕ 64** (исторической), а атлас в восемь раз
плотнее: пиксель сетки = 8 текселей (`KITNUM.scale` в `src/kitnum.js`). Так
разметку можно сверять с зонами в `tools/build-player-mesh.py` напрямую, а
рисовать швы, канты, шнуровку и эмблемы — с нормальной точностью.

История разрешения. До 24.08.2026 атлас был 64×64 и увеличивался в
`src/kitnum.js` вчетверо БЕЗ сглаживания — эмблема в 4×5 пикселей читалась
мусором, швов и затенения не было вовсе. Потом 256×256. 512 понадобились
ОДНОМУ плану — заставке матча (камера облёта мяча в 2.94 м): бутса там
занимает 146–217 пикселей, а её зона на 256 — всего 64 текселя, и шнуровка с
кантом подошвы рубились на квадраты. Память: 22 холста с мипами ≈ 30 МБ
против 7.7 — на iPad терпимо, вызовов отрисовки не прибавилось.

Фильтрация: увеличение ЛИНЕЙНОЕ, минификация с мипами, анизотропия 4
(`src/kitnum.js`). NearestFilter имел смысл, пока атлас был пиксель-артом;
нарисованный со сглаживанием атлас он только рубит на квадраты.

Путь к форме задаётся в `data/teams/*.json`:

```json
"kits": {
  "home": "./textures/kits/brazil-1998-home.png",
  "goalkeeper": "./textures/kits/brazil-1998-gk.png"
}
```

Готовые комплекты ЧМ-98:

- `brazil-1998-home.png` / `brazil-1998-gk.png`
- `france-1998-home.png` / `france-1998-gk.png`

Исходник разметки — `tools/paint-kit-textures.py` (Pillow). Повторный запуск
пересобирает все восемь PNG:

```
python3 tools/paint-kit-textures.py
```

Координаты в пикселях, **(0,0) — левый нижний угол** (как в Blender/OpenGL).

```
 64 ┌──────────────┬──────────────┐
    │ ПЕРЕД        │ СПИНА        │   верх зоны = плечи/воротник
    │ футболки     │ (номер −     │
    │              │  зона 32×32) │
 32 ├──────┬───────┼──────────────┤
    │РУКАВА│ БОКА  │ ШОРТЫ        │   рукав: правый край = манжета
    │      │ торса │              │
 16 ├──────┼───────┼──────┬───────┤
    │ГЕТРЫ │ БУТСЫ │ (запас под   │
    │      │       │  вратаря/№)  │
  0 └──────┴───────┴──────┴───────┘
    0     16      32      48     64
```

## Зоны

| Зона | Пиксели (x0,y0)–(x1,y1) | Проекция |
|---|---|---|
| Перед футболки | (0,32)–(32,64) | плоская, вид спереди; ВЕРХНЯЯ КРОМКА зоны = горловина (основание шеи), верхние 8 % — скат плеча |
| Спина футболки | (32,32)–(64,64) | плоская, вид сзади; сюда потом номера |
| Рукава | (0,16)–(16,32) | вдоль руки: fx 0 пройма, 1 манжета; ПО КРУГУ fy 0 перёд, **0.25 ВЕРХ**, 0.5 зад, **0.75 подмышка** |
| Бока торса | (16,16)–(32,32) | однотонная заливка (бока + подол снизу) |
| Шорты | (32,16)–(64,32) | fx 0 и 1 — БОКА, 0.5 — перед И спина (складывается); верх = пояс |
| Гетры | (0,0)–(16,16) | fx 0 — ГОЛЕНЬ, 1 — ИКРА, 0.5 — бока (складывается); верхние ряды (y=13–15) = отворот |
| Бутсы | (16,0)–(32,16) | fx 0 носок, 1 пятка; fy — АБСОЛЮТНАЯ высота над газоном / 10.5 см (верх колодки в каждом столбце свой) |
| Воротник | (32,8)–(64,16) | по кругу шеи; fy снизу вверх |
| Запас | (32,0)–(64,8) | заливка цветом формы (туда уходят крышки труб) |

Ориентации рукава и гетры замерены по сборщику и стендом 03.09.2026: прежний
рисовальщик считал fy 0/1 рукава швом под мышкой (полосы adidas печатались
ПОД рукавом), а перёд гетры — серединой зоны.

## Что НЕ в атласе

- **Кожа и голова** — отдельные материалы без текстуры кита; тон кожи
  задаётся числом из JSON игрока (`data/teams/*.json`).
- **Волосы** — отдельные модели-«шапки» (models/), цвет тоже из JSON.

## Советы по рисованию

- Вертикальные полосы на футболке рисуй в зонах «перед» и «спина» — лягут ровно.
- Бока торса однотонные: полоса, дошедшая до края переда, на боку не продолжится.
- 1 пиксель СЕТКИ ≈ 1 см на модели, то есть 1 тексель ≈ 1.3 мм.
- Мягкое затенение (подмышки, шаг, под воротом) рисуется отдельным слоем и
  размывается перед наложением: тень обязана быть мягкой, а кант — резким.
- Складка — это ПАРА «свет + тень» рядом (`Kit.fold`), а не тёмная черта:
  одиночная тёмная линия читается грязью.
- Фактура (зерно трикотажа, рубчик гетры, строчка) — третий слой `fine`, он НЕ
  размывается и в мипах сам сходит в ровный тон на эфирном плане.
- Окантовка горловины — полоса по ВЕРХНЕЙ кромке зоны переда/спины, не диск:
  диск на полотне висит «ожерельем» на 5 см ниже шеи.
- У воротника СВОЯ зона. Раньше он брал верхние 6 % зоны футболки, но туда же
  попадают широкие верхние кольца торса — полоса цвета ворота ложилась поперёк
  всех плеч, и реглановый рукав резал её клиньями.
