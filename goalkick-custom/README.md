# Teste Pedra Lisa no GoalKick

Bundle preparado em `goalkick-custom/data/teams/pedra-lisa/`.

## Próximo passo no GoalKick Editor
1. Baixar o GoalKick Editor da release oficial.
2. Abrir uma cópia do repositório `goalkick-game/goalkick-release`.
3. Copiar a pasta `pedra-lisa` para `data/teams/`.
4. Abrir o Editor apontando para a pasta `data`.
5. Abrir Pedra Lisa e gerar/importar `logo.png`, `kit_01.png` e `kit_02.png`.
6. Usar **Build database**.
7. Testar Pedra Lisa contra CPU antes de qualquer alteração no online.

O multiplayer oficial do GoalKick exige que os dois jogadores usem a mesma release/build. Por isso primeiro validamos o time localmente; depois fazemos a etapa online.
